Ringdown Spotlight

OngoingBlack-hole ringdown from catalog data

An independent computational project that calculates Kerr black-hole ringdown predictions for observed gravitational-wave events. It is built in Python and Jupyter and documented on GitHub.

  1. Select events. GW150914, GW200129 and GW170814.
  2. Compute predictions. Use the qnm package for quasinormal-mode frequencies and damping times.
  3. Transform frames. Convert source-frame values to detector-frame values with catalog redshifts.
  4. Document. Keep predictions and observations distinct, and record every input and assumption.
