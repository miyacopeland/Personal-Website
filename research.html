Ringdown Project

A self-directed computational project testing Kerr black-hole ringdown predictions against public catalog events (GW150914, GW200129 and GW170814), using Python, Jupyter notebooks and the qnm package.

  1. Select events. Choose events from the LIGO–Virgo catalog.
  2. Compute QNM predictions. Calculate predicted frequencies and damping times.
  3. Transform frames. Convert source-frame values to detector-frame values using catalog redshifts.
  4. Compare and document. Keep model predictions separate from measurements, and record inputs, assumptions and methods on GitHub.
